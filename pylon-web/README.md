# Pylon Web

React frontend for Pylon.

## Stack

- Bun
- Vite
- React
- TypeScript
- Tailwind CSS v4
- ESLint
- Prettier

## Commands

```fish
bun install
bun run dev
bun run lint
bun run build
bun run format:check
```

## Environment

```fish
cp .env.example .env
```

```text
VITE_API_BASE_URL=http://localhost:8080
```
